# Asli packages ka content — kaise bharna hai

Website par abhi **6 sample packages** hain (daam aur din-wise plan dummy). Asli content inhi do
sheets me bhar ke wapas do — main website me daal dunga.

## 1. `packages.csv` — har package ki ek line

Excel / Google Sheets me kholo (File → Import). Pehli line ek udaharan hai — use badal do ya
hata do.

| Column | Kya likhna hai |
|---|---|
| package_naam | Jaise "Royal Rajasthan Circuit" |
| din / raat | 7 / 6 |
| kahan_se_shuru / kahan_khatam | Shehar ka naam |
| route_kram_se | Shehar `>` laga ke, jis kram me jayenge |
| dzire_rate / ertiga_rate / crysta_rate | Poore package ka daam, ₹ me, sirf number |
| rate_me_shaamil | Kya daam me hai (gaadi, driver, diesel…) |
| shaamil_nahi | Kya alag dena hoga (GST, hotel, ticket, toll…) |
| hotel_ke_saath_rate_per_person | Agar hotel ke saath bechna hai, warna khaali |
| sabse_achha_mausam | Jaise "October-March" |
| kis_ke_liye | Family, couple, group, pilgrims… |
| photo_file_naam | Neeche photo wale hisse ka file naam |

## 2. `itinerary.csv` — har package ke har din ki ek line

subah / dopahar / shaam me kya dekhna, raat kahan rukna, us din ka lagbhag km.

## 3. Photos

- **Sirf apni ya apne drivers ki khinchi photo** — kisi website, Google ya Instagram se uthayi
  hui nahi (copyright notice aata hai, site hatwayi ja sakti hai).
- Phone se khinchi chalegi — din ki roshni me, seedhi, saaf.
- Har photo ka naam jagah ke hisaab se: `jaisalmer-dunes-1.jpg`, `udaipur-pichola-2.jpg`.
- Google Drive folder me daal ke link bhej do.

## Dhyan rakhna

- Daam wahi likho jo sach me lena hai — website par jo likha hoga customer wahi maangega.
- Koi jagah raste me nahi padti to mat likho — customer raste me poochhega.
